# AgilePME

Protótipo acadêmico desenvolvido para o TCC II do curso de Engenharia de Software.

## Objetivo

O AgilePME é uma aplicação web para apoiar pequenas empresas na organização e no acompanhamento de projetos utilizando conceitos de Scrum e Kanban.

## Funcionalidades

- Tela de autenticação para demonstração
- Dashboard com indicadores
- Quadro Kanban
- Gerenciamento visual de sprints
- Relatórios resumidos
- API para consulta e cadastro de tarefas
- Persistência de tarefas com SQLite

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Node.js
- Express
- SQLite

## Como executar

1. Instale o Node.js.
2. Abra o terminal na pasta do projeto.
3. Execute:

```bash
npm install
```

4. Depois execute:

```bash
npm start
```

5. Abra no navegador:

```text
http://localhost:3000
```
